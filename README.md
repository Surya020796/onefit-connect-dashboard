# OneFit Connect: Before vs After Dashboard (Team 4)

Static dashboard (HTML, bundled Chart.js, no server needed). Five tabs: Overview, Analysis, Before vs After, Data Explorer and Utilization Deep Dive. It compares the baseline 2,700-session dataset with the projected improved dataset.

Files: index.html, chart.umd.js, summary.js (KPI aggregates), sessions.js (all 2,700 sessions, before and after), the two session CSVs, the Excel workbook and the Python scripts that generate the data.

## Publish on GitHub Pages
Upload all files to the root of a repository, then Settings > Pages > Deploy from branch (main, / root).
